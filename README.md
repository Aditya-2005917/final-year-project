# Final Year Project: Property Price Prediction (MMR Region)

## 🧠 Overview
An AI-powered model designed to predict property prices across the Mumbai Metropolitan Region (MMR) using machine learning techniques.

## 📊 Features
- Data preprocessing and feature engineering for real estate datasets  
- Regression models (Linear, Random Forest, XGBoost)  
- Visualization dashboards for price trends  

## 🧰 Tech Stack
- Python (Pandas, Scikit-learn, Matplotlib)
- Flask for backend integration
- Power BI/Tableau for visualization

## 🚀 How to Run
1. Clone the repository  
2. Install dependencies using `pip install -r requirements.txt`  
3. Run `app.py` to start the Flask server
